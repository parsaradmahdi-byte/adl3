# راه عدالت — نسخه گرافیکی GitHub

این نسخه برای کاربرانی ساخته شده که Android Studio ندارند. ساخت APK روی GitHub Actions انجام می‌شود.

## جریان فعلی
Splash → دفتر وکیل → کتابخانه → پرونده ۰۱ → گفت‌وگو → بررسی مدارک → سؤال حقوقی → بازخورد → دفتر

## عناصر کاربردی دفتر
- کتابخانه: انتخاب پرونده‌ها
- پرونده روی میز: ادامه پرونده جاری
- مانیتور: پیشرفت آموزشی
- کتاب قانون: واژه‌نامه و مطالب حقوقی
- بایگانی: پرونده‌های تکمیل‌شده
- تنظیمات/صدا: محل رزرو شده برای نسخه بعدی

## گرافیک
- دفتر وکیل و کتابخانه از تصاویر گرافیکی تولیدشده استفاده می‌کنند.
- کاراکترها به صورت فایل‌های جداگانه در drawable-nodpi قرار گرفته‌اند.
- متن فارسی، دکمه‌ها و UI در خود Android ساخته می‌شوند تا قابل تغییر و responsive باشند.
- طراحی portrait و responsive است و به 1080×2400 قفل نشده است.

## آموزش حقوقی
محتوای نسخه اول حول مفاهیم مقدماتی «خواهان، خوانده، خواسته، دادخواست و درخواست رسیدگی» است.
مبنای اولیه بررسی‌شده برای این نسخه:
- ماده ۲
- ماده ۴۸
- ماده ۵۱
قبل از افزودن مواد بیشتر یا اصلاحات قانونی، متن جاری باید دوباره راستی‌آزمایی شود.

## ساخت APK
1. فایل‌های این ZIP را در ریشه repository خود قرار دهید.
2. به GitHub push کنید.
3. به Actions بروید.
4. workflow با نام `Build Rah Edalat APK` را باز کنید.
5. Artifact با نام `RahEdalat-Graphic-Debug-APK` را دریافت کنید.

Android Studio روی دستگاه شما لازم نیست.
